# Image Attribution

## Dataset Examples

The presentation contains three low-resolution MRI examples copied from the local project data:

| Published asset | Local source class | Purpose |
| --- | --- | --- |
| `presentation/assets/mri_non_demented.jpg` | `Non_Demented` | Task example and interactive anatomy backdrop. |
| `presentation/assets/mri_very_mild.jpg` | `Very_Mild_Demented` | Task example. |
| `presentation/assets/mri_mild.jpg` | `Mild_Demented` | Task and class-comparison example. |

The local data were attributed to Kaggle's [Alzheimer's Dataset (4 class of Images)](https://www.kaggle.com/datasets/tourist55/alzheimers-dataset-4-class-of-images). The source page may require authentication or may no longer be available. Verify the current source, ownership, and terms before reusing these images outside this educational project.

The examples are not matched longitudinal scans and must not be interpreted as a controlled visual comparison between healthy and Alzheimer disease brains.

## Generated Figures

The PNG files under `results/figures/` and their copies under `presentation/assets/` were generated from this project's saved CSV outputs by `scripts/presentation/generate_model_insight_plots.py`. They include:

- LDA validation projection.
- MLP ROC curve.
- MLP threshold operating points.
- Test error counts.
- Regional occlusion analysis.

Confusion-matrix images were generated by the experiment scripts from project predictions. No external logos or stock illustrations are included.
