# Real Estate Price And Risk Prediction

Predicts real-estate sale price and distressed-sale probability from structured
property features. The project emphasizes reliable validation, calibrated
probabilities, feature importance, and reproducible prediction artifacts.

## Key Artifacts

- `real_estate_risk_slides.pdf` - concise presentation.
- `real_estate_risk_results.json` - final prediction artifact.
- `real_estate_risk_summary.txt` - result summary.
- `real_estate_risk_code.py` and `real_estate_risk_slides_code.py` -
  reproducible analysis and presentation code.
- `real_estate_risk_train.csv` and `real_estate_risk_test.csv` - project data.

## Validation Work

The `experiments/` folder contains data-cleaning checks, price-prediction
benchmarks, probability-scoring comparisons, imbalance handling, calibration
diagnostics, feature-importance outputs, and repeated/nested validation results.
