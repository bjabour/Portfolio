# Portfolio

Selected end-to-end statistical learning and machine learning projects. Each project includes its implementation, validation evidence, results, and supporting documentation.

## Projects

- [Early Alzheimer MRI Prediction](early-alzheimer-mri-prediction/) - transforms 2D brain MRI images into deterministic features and compares MLP, SVM, and CNN approaches. The selected two-stage MLP prioritizes a low missed-dementia rate and documents the false-positive tradeoff.
- [Energy Demand Prediction](energy-demand-prediction/) - predicts energy consumption and high-demand alert probability from temperature, humidity, and weekend indicators.
- [Real-Estate Price and Risk Prediction](real-estate-price-risk-prediction/) - predicts sale price and distressed-sale probability with validation, calibration, and feature-importance checks.

## Repository Structure

All three project directories live directly at the repository root, so they are immediately accessible from this main portfolio page. Each project keeps its primary deliverables and overview at its top level, with supporting code, configuration, documentation, data instructions, and results organized by role.
