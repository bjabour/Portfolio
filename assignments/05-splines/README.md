# 05 - Splines

Spline and nonlinear modeling project with final deliverables plus validation experiments.

## Main Deliverables

- `splines_slides.pdf` - final presentation.
- `splines_results.json` - submitted results artifact.
- `splines_summary.txt` - concise result summary.
- `splines_code.py` and `splines_slides_code.py` - reproducible modeling and slide-generation code.
- `splines_train.csv` and `splines_test.csv` - project data.

## Experiments

The `experiments/` folder includes EDA plots, fixed-knot comparisons, nested cross-validation benchmarks, pseudo-DGP Monte Carlo checks, and test scripts used to validate spline choices.
