# 06 - Trees

Tree-based modeling project covering CART, random forests, XGBoost regression/classification, and imbalance-aware classification checks.

## Main Deliverables

- `trees_slides.pdf` - final presentation.
- `trees_results.json` - submitted results artifact.
- `trees_report.txt` and `trees_summary.txt` - written outputs.
- `trees_code.py` and `trees_slides_code.py` - reproducible code.
- `trees_train.csv` and `trees_test.csv` - project data.

## Experiments

The `experiments/` folder contains model-specific experiment suites and checks for CART, random forests, logistic-vs-tree classifiers, random-forest classification, XGBoost regression/classification, data cleaning, and tree-imbalance comparisons.

## Portfolio Pack

The `portfolio_pack/` folder contains a condensed professional profile of the project, including artifact manifests, resume bullets, talking points, metrics, and selected final artifacts.

## Support

The `support/` folder contains the original instructions and progress/testing notes.
