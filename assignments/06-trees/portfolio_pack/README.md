# trees Tree-Based Modeling Portfolio Pack

This folder is a portable CV/portfolio packet for the tree-based modeling project. It is intended to be moved into a separate CV-generation project without requiring the full course workspace.

## Recommended CV Title

Tree-Based Real Estate Modeling: Scratch CART, Scratch Random Forest, and XGBoost

## One-Line Summary

Built and validated five tree-based models for Ames housing price prediction and distressed-sale probability estimation, including scratch CART and random-forest implementations, leakage-safe cross-validation, probability calibration, and imbalanced-class handling.

## Best Use In A CV

- Use `resume_bullets.md` for short resume bullets.
