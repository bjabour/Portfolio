# CV Project Requirements And Available Inputs

## Purpose

This packet gives another Codex/CV project enough structured material to turn trees into a professional resume entry, portfolio page, or interview preparation note.

## Required CV Inputs Included

- Project title and one-line summary
- Business/data context
- Technical stack
- Core modeling methods
- Quantitative results
- Validation and leakage-control story
- Resume bullet variants
- Interview talking points
- Proof of final score
- Artifact manifest

## Recommended Framing

Frame this as a rigorous academic machine-learning project with production-relevant practices:

- scratch implementation of core algorithms
- validation discipline
- calibrated probability modeling
- imbalanced-class handling
- explainable feature importance
- compact reproducible code and slides

## Suggested Skills To Extract

- Python scientific stack: NumPy, pandas, matplotlib, seaborn
- scikit-learn model selection and calibration
- XGBoost regression and classification
- manual CART and random forest implementation
- repeated cross-validation and out-of-bag diagnostics
- log loss, MSE/RMSE, Brier score, AUC
- model interpretation using MDI and total gain

## Cautions For CV Wording

- Say "course project" or "academic project" unless the target CV format intentionally omits context.
- Do not claim production deployment.
- Do not say the model beat the oracle. The report gave full score, but an oracle is by definition the best possible model.
- Prefer "earned 100/100" over vague claims like "state-of-the-art."
