# 02 - Classification

Classification project with final deliverables and curated logistic-regression/model-selection experiments.

## Main Deliverables

- `classification_slides.pdf` - final presentation.
- `classification_results.csv` - submitted results file.
- `classification_summary.txt` - written result summary.
- `classification_code.py` and `classification_slides_code.py` - reproducible modeling and slide-generation code.
- `classification_train.csv` and `classification_test.csv` - project data.

## Experiments

The `experiments/` folder contains focused checks for polynomial terms, logistic linearity, term selection, no-intercept/omitted-effect sensitivity, and exploratory plots used to justify the submitted model.

## Support

The `support/` folder contains the original instructions and presentation notes.
