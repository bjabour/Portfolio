# 04 - Regularization

Regularization project with LASSO artifacts, error-decomposition experiments, slides, summary, and data.

## Main Deliverables

- `regularization_slides.pdf` - final presentation.
- `regularization_results.json` - submitted results artifact.
- `regularization_summary.txt` - written result summary.
- `regularization_explanation_appendix.pdf` - appendix explaining model choices.
- `regularization_code.py` and `regularization_slides_code.py` - reproducible code.
- `regularization_train.csv` and `regularization_test.csv` - project data.

## Experiments

The `experiments/` folder contains LASSO grid outputs and error-decomposition checks.
