# Regularized Response Prediction

Regularized prediction analysis comparing shrinkage and sparse coefficient
selection under cross-validation and bootstrap stability checks.

## Key Artifacts

- `regularization_slides.pdf` - concise presentation.
- `regularization_results.json` - prediction and coefficient artifact.
- `regularization_summary.txt` - result summary.
- `regularization_explanation_appendix.pdf` - modeling appendix.
- `regularization_code.py` and `regularization_slides_code.py` - reproducible
  analysis and presentation code.
- `regularization_train.csv` and `regularization_test.csv` - project data.

## Validation Work

The `experiments/` folder contains regularization grid outputs and
error-decomposition checks.
