This solution fits regularized linear regression models to 150 training observations with 40 correlated predictors and a continuous response. Ridge regression was implemented from scratch in two ways: a closed-form matrix solution and gradient descent. I used manual 5-fold cross-validation over the required 80-value lambda grid, standardizing predictors inside each fold using only that fold's training rows. The selected ridge penalty was lambda = 0.232857, with minimum mean validation MSE = 13.666636. The gradient-descent ridge predictions agree with the closed-form ridge predictions almost exactly, with GD vs closed-form RMSE about 2.25e-11.

Lasso regression was fit with sklearn LassoCV, using its cross-validated alpha path. The selected lasso alpha was 0.211718, with lasso CV MSE = 12.645898. Lasso selected 17 nonzero predictors. Compared with ridge, lasso gives a sparse model by setting some coefficients exactly to zero, while ridge keeps all 40 coefficients but shrinks them toward zero.

To assess selection stability, I ran 200 bootstrap lasso refits. For each bootstrap sample, the model recorded which predictors had nonzero lasso coefficients, producing a 40-variable selection-frequency vector. Variables selected with frequencies near 1 are stable across resampled datasets, while variables near the middle of the frequency range are less stable and may reflect correlation among predictors. The final JSON file contains ridge and lasso test predictions, ridge CV results, fitted coefficients, lasso selected variables, and bootstrap selection frequencies.
