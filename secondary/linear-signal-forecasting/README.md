# Linear Signal Forecasting

Interpretable regression analysis focused on identifying meaningful predictors
and interaction effects while preserving a transparent specification.

## Key Artifacts

- `regression_slides.pdf` - concise presentation.
- `regression_results.csv` - prediction output.
- `regression_summary.txt` - result summary.
- `regression_code.py` and `regression_slides_code.py` - reproducible analysis
  and presentation code.
- `regression_train.csv` and `regression_test.csv` - project data.
