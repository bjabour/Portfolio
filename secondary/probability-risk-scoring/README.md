# Probability Risk Scoring

Binary probability-scoring project focused on nonlinear signal detection,
validation log loss, ranking quality, and interpretable probability estimates.

## Key Artifacts

- `classification_slides.pdf` - concise presentation.
- `classification_results.csv` - prediction output.
- `classification_summary.txt` - result summary.
- `classification_code.py` and `classification_slides_code.py` - reproducible
  analysis and presentation code.
- `classification_train.csv` and `classification_test.csv` - project data.

## Validation Work

The `experiments/` folder contains probability-surface checks, term-selection
experiments, nonlinear boundary diagnostics, and model-comparison artifacts.
