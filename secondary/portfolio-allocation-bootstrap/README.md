# Portfolio Allocation Bootstrap

Minimum-variance allocation analysis using paired asset returns and bootstrap
uncertainty estimation.

## Key Artifacts

- `resampling_slides.pdf` - concise presentation.
- `resampling_solution_explanation.md` - methodology explanation.
- `resampling_summary.txt` - result summary.
- `resampling_code.py` and `resampling_slides_code.py` - reproducible analysis
  and presentation code.
- `resampling_data.csv` and `resampling_bootstrap.csv` - source and bootstrap
  result data.

## Validation Work

The `tests/` folder contains the final verification script.
